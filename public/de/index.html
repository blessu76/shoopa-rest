Pfeil-Tipppuzzle

Shoopa

Finde den Weg und tippe.

Tippe einen Pfeilblock an, sobald sein Weg frei ist. Finde die richtige Reihenfolge und räume das Brett Stück für Stück leer.

Spielanleitung

So läuft eine Runde ab

  • ↗

    Finde einen freien Weg

    Ein Block kann das Brett verlassen, wenn in Pfeilrichtung bis zum Rand alle Felder frei sind.

  • ϟ

    Kombos in 0,9 Sekunden

    Entferne den nächsten Block innerhalb von 0,9 Sekunden, um die Kombo fortzusetzen. Tippst du auf einen blockierten Block, endet die Kombo.

  • ♥

    Drei Herzen, zwei Hinweise

    Tippst du einen blockierten Pfeil an, verlierst du ein Herz. Du kannst dasselbe Brett kostenlos erneut spielen.

Pläne zum Start

Zum Start kannst du ohne Werbung auf Spielbrettern von 5×5 bis 9×9 spielen. Wir bereiten die Ranglisten „Bestes Level“ und „Beste Tageskombo“ vor. Für die beste Tageskombo zählen nur Versuche, die ohne Hinweis den Ergebnisbildschirm erreichen.
